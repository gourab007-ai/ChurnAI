About the Data

The data has been sourced from banks across France, Spain and Germany. The dataset has 14 original features and 10,000 instances, with the target variable being "Exited" (1 = Churned, 0 = Retained). The overall churn rate is approximately 20.4%. 6 additional engineered features were added during preprocessing to improve model performance.
