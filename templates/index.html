About

A Complete Machine Learning approach to classify Bank Customers based on the class "Churn". Built using TensorFlow and Keras with a deep neural network trained on 10,000 customer records from banks across France, Germany, and Spain. The model achieves 85.35% accuracy using SMOTE oversampling, feature engineering, and optimal threshold tuning.
