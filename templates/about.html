Info

This is a Classification Model built using the Keras framework from the TensorFlow library. The model uses the Sequential API and consists of 5 Dense layers with LeakyReLU activations, Batch Normalization, and Dropout regularisation. It has a total of 18 input features including 6 engineered features. The model is trained with SMOTE oversampling to handle class imbalance, and uses an optimal threshold of 0.68 for binary classification. The prediction accuracy of the model is found to be 85.35% with an AUC-ROC score of 0.8599, which is a strong result for customer churn prediction.
